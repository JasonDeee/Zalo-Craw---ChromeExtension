# Kịch bản video giới thiệu Zalo Chat Crawler (60-90 giây)

| Thời gian  | Hình ảnh trên màn hình                                                                 | Lời thoại (voice-over)                                                                          |
| ---------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 0-5 giây   | Màn hình chat Zalo, người dùng **copy → paste** thủ công từng tin vào Excel/Notepad.   | “Bạn vẫn đang lọ mọ chép từng tin nhắn Zalo?”                                                   |
| 5-10 giây  | Nhấp đúp biểu tượng **"Zalo Chat Crawler"** trên desktop để mở ứng dụng.               | “Giới thiệu Zalo Chat Crawler – công cụ thu thập dữ liệu chat chỉ với một cú bấm.”              |
| 10-35 giây | Trình duyệt Chrome, nhấp biểu tượng extension → bấm **"Quét"**. Cửa sổ chat tự cuộn.   | “Bấm 'Quét', công cụ tự động lấy toàn bộ tin văn bản và hình ảnh, bỏ qua tin đã thu hồi.”       |
| 35-50 giây | Bảng kết quả (panel) hiện JSON; nhấn dấu **"+"** thêm một tin, sửa nhanh nội dung.     | “Bạn có thể chỉnh sửa hoặc thêm ghi chú ngay trên màn hình trước khi lưu.”                      |
| 50-60 giây | Nhấn **"Copy JSON"**, chuyển sang Excel/Google Sheet dán kết quả.                      | “Chỉ một cú click để sao chép và sử dụng dữ liệu ở bất kỳ đâu.”                                 |
| 60-75 giây | Quay lại cửa sổ desktop app, lướt qua icon Windows/macOS/Linux và dung lượng file nhỏ. | “Ứng dụng gọn nhẹ, chạy trên mọi hệ điều hành và hoàn toàn miễn phí.”                           |
| 75-85 giây | Mở nhanh file cấu hình trong VS Code, dòng code hiện lên vài giây.                     | “Cần thêm chức năng? Bạn (hoặc kỹ thuật viên) có thể mở rộng để lưu ảnh khách hay kết nối CRM.” |
| 85-90 giây | Logo Zalo Chat Crawler + dòng chữ **"Tải miễn phí hôm nay"**.                          | “Tải ngay Zalo Chat Crawler – tiết kiệm thời gian, làm chủ dữ liệu!”                            |

> Video chỉ gồm quay màn hình và thuyết minh, không cần hiệu ứng phức tạp, pop-up hay phụ đề màu mè. Quay thực tế, tốc độ hơi nhanh (1.25x) để đủ thời lượng.
